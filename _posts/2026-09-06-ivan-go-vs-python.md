Несколько лет писал на Python. Потом перешёл на Go.


## Почему Go

Компилируется в один бинарник. Сильная типизация.
Простой синтаксис — легко читать чужой код.


## Когда Python

Для скриптов, прототипов и автоматизации — Python по-прежнему удобен.
Для сервисов с нагрузкой — Go однозначно.


## Итог

Не нужно выбирать одно навсегда. Используйте подходящий инструмент.
