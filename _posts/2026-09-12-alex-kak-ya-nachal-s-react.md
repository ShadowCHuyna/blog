Раньше я писал на jQuery. Сейчас пишу на React и не жалею.


## Почему React

Понравилась модель компонентов и декларативный подход.
Писать UI стало проще и приятнее.


## Что использую

TypeScript, Next.js, Tailwind. Иногда стандартный CSS.
Главное — не гнаться за каждым новым фреймворком.


## Итог

Начал с простого, дошёл до продакшена.
React — хороший выбор для веб-фронта.
