# 🥔 PotatoNet — Простой P2P VPN

> Нативное приложение для создания приватных сетей поверх [EasyTier](https://github.com/EasyTier/EasyTier).
> Аналог Hamachi или Radmin VPN, но без лишней бюрократии.

**Суть проста:** Ввели имя сети + Пароль + Имя устройства = Вы в одной сети с друзьями.
Никаких серверов, никакой регистрации. Приложение — один исполняемый файл на базе [Wails v2](https://wails.io).

## 🚀 Быстрый старт

*Для тех, кто не любит читать длинные мануалы и хочет играть/работать прямо сейчас.*

### 1. Скачайте приложение
Перейдите в раздел **[Releases](../../releases)** и скачайте последнюю версию для вашей ОС:

- 🐧 **Linux:** `PotatoNet-linux-x64.AppImage` (или deb/rpm)

- 🪟 **Windows:** `PotatoNet-setup-x64.exe`

### 2. Запустите

- **Linux:** Сделайте файл исполняемым (`chmod +x PotatoNet-*.AppImage`) и запустите.
- **Windows:** Просто запустите установщик.

### 3. Подключитесь к сети
В открывшемся окне добавьте сеть и заполните всего три поля:

| Поле | Что писать? | Пример |
| :--- | :--- | :--- |
| **Имя сети** | Любое уникальное название. Должно совпадать у всех участников. | `MySuperGameNight` |
| **Пароль** | Секретный ключ сети. Без него не подключиться. | `secret123` |
| **Имя устройства** | Как вас будут видеть другие. Можно оставить пустым (возьмется hostname). | `BorkTheCat` |

👉 Нажмите кнопку **"Подключиться"**.

### 4. Готово!
Вы увидите список подключенных устройств. Теперь вы можете пинговать их по IP-адресу из списка.

## 🖥 Интерфейс

![i](/assets/imgs/screen.webp)

Всё максимально просто, никаких лишних настроек, которые сбивают с толку:

- **Имя сети** — сети с одинаковым именем и паролем видят друг друга.
- **Пароль** — общий секрет сети.
- **Имя устройства (hostname)** — как вас видят другие.
- **Список устройств** — таблица подключенных узлов. Показывает:
    *   IP-адрес
    *   Имя
    *   Тип соединения
    *   Задержку (Ping) и потери пакетов
    *   Трафик и статус NAT
- **Несколько сетей** — можно добавить сколько угодно сетей; каждая отображается отдельной карточкой.
- **Опции** — автозапуск при входе в систему: приложение стартует и сразу подключается к сохраненным сетям.

## 🛠 Сборка Linux

**Требования**: `Go`, `curl` и `unzip`, [Wails v2](https://wails.io).

Установите Wails:
```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

`Makefile` автоматически находит `wails` в `PATH` или в `$(go env GOPATH)/bin`.

**Команды сборки**

```bash
make run        # Собрать и запустить в режиме разработки (Linux)
make build      # Сборка релизной версии в папку build/dist-linux/
make test       # Запуск тестов
```

Результат сборки Linux находится в `build/dist-linux/` (исполняемый файл `PotatoNet` + бинарник EasyTier рядом).

**Настройка Bootstrap-сервера**

Версия приложения хранится в файле `VERSION` и автоматически подставляется во все артефакты (бинарник, установщики, пакеты).

По умолчанию используется публичный bootstrap, но вы можете задать свой при сборке **без правки кода**:

```bash
# Один сервер
make build BOOTSTRAP=udp://my.server:11010

# Несколько серверов через запятую
make build BOOTSTRAP=udp://s1.example.com:11010,udp://s2.example.com:11010
```

Для уже собранного приложения сервер можно переопределить через переменную окружения `POTATONET_BOOTSTRAP` или файл `config.yml`.

**AppImage**

```bash
make appimage   # Создает build/PotatoNet-linux-x64.AppImage
```

### 🪟 Сборка под Windows (из Linux)

Требуется кросс-компиляция. Убедитесь, что установлены: `mingw-w64`, `curl`, `unzip`, `zip`, `upx`.

```bash
# Просто сборка бинарника
make build PLATFORM=windows      # Результат в build/dist-win/

# Создание установщика (.exe)
make installer PLATFORM=windows  # Результат: build/PotatoNet-setup-x64.exe
```

> ⚠️ **Важно:** Файл `easytier-core.exe` намеренно **не сжимается** через UPX. После сжатия UPX у Rust-бинарников ломаются таблицы исключений, и приложение падает с ошибкой `0xc0000005`.
